# @max/dsh-json-formatter

JSON Formatter and Tree Inspector plugin for DeepSeek Harness Better Sidebar.

`AGENTS.md` stays short on purpose. Treat it as a map, not the encyclopedia. Repository-local markdown under `docs/` is the system of record.

If changes make a doc stale, update the doc in the same task.

## Read At The Start Of Each Task
- `docs/REPO_COLLAB_GUIDE.md`: Collaboration, verification, and code quality expectations.
- `docs/ARCHITECTURE.md`: Module boundaries, Better Sidebar extension contract, data flow.

## Read When The Task Needs It
- `docs/exec-plans/`: Stateful task execution plans for new capabilities or refactoring.

## Read Before Finishing A Task
- `docs/histories/`: Record finished change logs following `docs/histories/` convention.
